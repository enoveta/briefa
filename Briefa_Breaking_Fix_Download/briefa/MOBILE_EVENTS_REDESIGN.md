# Briefa mobile Events page redesign

Updated `frontend/src/App.css` with a mobile-only redesign for the Events & Announcements category page.

- Refined the events hero into a soft cyan editorial panel with stronger type hierarchy.
- Reworked the event filters into compact, touch-friendly controls.
- Changed event cards on narrow screens to polished image-and-copy cards with readable typography and better spacing.
- Added smaller-screen adjustments for phones under 390px.
- All changes are scoped to the Events category page at mobile widths; desktop styling and other categories are left untouched.

The project build was not run in this environment because dependencies are not installed.
